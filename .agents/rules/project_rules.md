# Pizza World Project Rules & Constraints

## 1. UI Lock & Menu Book Invariance
- **DO NOT MODIFY** the Menu Book UI, 3D book physics, page layout, cover design, double-ruled border framing, 4-items-per-page rule, or current visual styling unless the user explicitly requests a specific change.
- The 3D Digital Menu interface is finalized and approved by the user.

## 2. Explicit User Permission Required
- **DO NOT CHANGE** any other existing features, themes, components, or configurations without explicit permission and instruction from the user.
- Always ask for confirmation before making architectural or design alterations outside the user's direct prompt.

## 3. Core Design & Formatting Standards
- **Currency**: Indian Rupees (`₹` / INR).
- **Typography**: Clean Title Case / Camel Case ONLY (never use `uppercase` classes or all-caps).
- **Food Badges**: Indian Regulatory standard 🟢 (Vegetarian) and 🔴 (Non-Vegetarian).
- **Pagination**: Strict maximum 4 items per page.
- **Responsiveness**: Dual-mode (2-page spread on desktop/laptop ≥ 768px; 1-page full-width flip on mobile < 768px).
- **Viewport**: 100vh lock with zero browser scrollbars.
